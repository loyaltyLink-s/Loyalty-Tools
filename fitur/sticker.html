Buat Stiker

Upload gambar, tambahkan teks, lalu unduh hasilnya.

Gambar pertama jadi latar belakang (tetap, tidak bisa digeser). Gambar berikutnya jadi overlay yang bisa digeser, di-zoom, dan diputar — tapi selalu berada di bawah lapisan teks.

Teks

Pilih chip teks di atas untuk edit teks itu. Seret di atas gambar untuk mengatur posisinya. Tekan enter di kolom teks untuk ganti baris.

Gambar Overlay
Belum ada gambar overlay. Upload gambar kedua (dan seterusnya) untuk menambahkan.

Pilih chip gambar di atas, lalu seret di atas kanvas untuk memindahkannya, atau atur slider zoom/putar.

File WEBP sudah berukuran 512×512 sesuai standar stiker WhatsApp. Cara paling aman: klik "Unduh PNG", lalu buka aplikasi Sticker Maker secara manual → pilih menu "buat paket baru" / "+" → "pilih dari galeri" → ambil gambar yang tadi diunduh. Tombol "Kirim ke Aplikasi Stiker" bisa dicoba juga, tapi kalau muncul pesan "invalid sticker pack file", itu artinya aplikasinya salah mengira file ini adalah paket stiker jadi — gunakan cara unduh manual di atas. Belum punya aplikasinya? Cari "Sticker Maker" di Play Store atau App Store.
